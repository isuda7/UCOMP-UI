기본 트리거 설정

trigger 스크롤 트리거가 걸릴 대상 요소
start 애니메이션이 시작될 시점. "top center" 형식 등 사용 가능
end 애니메이션이 끝날 시점. "bottom top" 형식 등 사용 가능
markers 마커 표시 여부 (true 사용 시 디버깅용 마커 표시)

위치 기준 설정

start: "top 80%"

트리거 요소의 top이 뷰포트 80% 지점에 닿을 때 시작

요소 기준 위치 : "top", "center", "bottom"

뷰포트 기준 위치 : "top", "center", "bottom" 또는 픽셀, 퍼센트

동작 제어 옵션

toggleActions

onEnter onLeave onEnterBack onLeaveBack 순서로 실행할 액션 지정

예: "play pause resume reset"


onEnter: 트리거 범위에 진입할 때 (아래로 스크롤 중)

onLeave: 트리거 범위에서 벗어날 때 (계속 아래로 스크롤)

onEnterBack: 트리거 범위에 역방향으로 진입할 때 (위로 스크롤)

onLeaveBack: 트리거 범위에서 역방향으로 벗어날 때 (계속 위로 스크롤)
scrub true, false, 또는 숫자 (디레이 지연값). 스크롤과 애니메이션을 동기화
pin 트리거 요소를 고정 (pinning)할지 여부
pinSpacing pin 고정 시 주변 여백 유지 여부 (true, false)
anticipatePin 스크롤 핀 전 예측값. 빠르게 고정될 수 있도록 조정

이벤트 콜백

onEnter, onLeave,
onEnterBack, onLeaveBack		 각 스크롤 방향에서 트리거될 콜백 함수
onUpdate 스크롤 상태 업데이트 시마다 호출되는 함수
onToggle 활성화/비활성화 될 때마다 호출

추가 설정

id ScrollTrigger 인스턴스 식별용 ID
containerAnimation 수평 스크롤 등에서 내부 애니메이션을 스크롤로 제어
horizontal 수평 스크롤 모드 (true 시 X축 기준 스크롤)
invalidateOnRefresh 리프레시 시 시작/끝 값 재계산 여부
once 애니메이션이 한 번만 실행되도록 설정

기본

document.addEventListener("DOMContentLoaded", function() { gsap.registerPlugin(ScrollTrigger); ScrollTrigger.create({ trigger: ".section-c", start: "top top", }); });
